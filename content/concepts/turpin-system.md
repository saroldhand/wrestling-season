The paper version of the system, captured. **Bread and Butter** is what the
team runs — those items live as move files and most sit on the
[[six-position-systems|system board]]. The **Encyclopedia** is the reference
shelf: named so we can talk about it, expanded into move files only when we
commit to teaching it.

## Bread and Butter

### Offense

- [[neutral-single-leg|Head outside single]] → run the pipe · double off · rotate
- [[neutral-head-inside-single|Head inside single]] → circle far ankle · shelf → limp arm / cradle
- [[neutral-double-leg|Double leg]] → blast · cut the corner
- [[scramble-sprawl-spin|Reattacks / go-behinds]]

### Defense (the base line)

- [[neutral-down-block|Down block]]
- [[neutral-sprawl-front-headlock|Sprawl]]
- [[scramble-whizzer|Whizzer]] → circle to bury · far ankle · hip block · tight waist · knock-down
- [[neutral-crossface|Crossface]] vs head inside — weight on the attacked leg, block the inside arm

### Top

- [[top-arm-bar|Arm bars]] · [[top-half-nelson|Half]] · [[top-tight-waist-arm-chop|Tight waist]]
- [[top-head-lever|Head lever]]
- [[top-head-inside-cradle|Head inside cradle]] · [[top-head-outside-cradle|Head outside cradle]]

### Bottom

- Block off, work up — [[bottom-position]] into [[bottom-standup]]
- [[bottom-switch|Switch]]
- [[bottom-knee-slide|Knee slide]]

### Cover

- Front headlock, top and bottom of it — [[neutral-sprawl-front-headlock]] is
  our entry; the bottom-of-the-headlock answers still need their own file.
